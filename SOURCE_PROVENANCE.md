# Source Provenance

This repository starts from a clean export of committed application source
`cfb55e69caed52350ce38adca6a83e90c660ddb4`, prepared on November 8, 2026.

Backend/frontend application source, migrations, dependency locks, operations
scripts, and existing test code were preserved byte-for-byte from that revision.
English publication documentation, repository hygiene rules, and manual-only CI
were added or revised for this repository.

The original private commit history, untracked/ignored files, QA captures,
credentials, private configuration, uploads, and database backups are not imported.
This repository has its own publication commit identity. That commit must not be
confused with the application revision currently running on the hosted website.

Existing synthetic credentials in tests and local-demo documentation are
intentional fixtures, not production credentials. Deployment ownership identifiers
in source are validation boundaries, not API keys or authorization grants.

A static credential-pattern scan and exact source comparison were performed for
publication. They are not a complete security audit or real-money certification.
